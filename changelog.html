The change trail

Every provenance entry from every rule, newest first. It answers one question — do I have to act? — which is why each entry carries a class, not just a diff.

ClassMeansWho has to act
token A colour, a spacing — the value behind a variable. Nobody. Components follow the variable. If this class still costs a review round, the tokens are being maintained twice.
rule A threshold, a condition, a rung of a ladder. Engineering — the implementation is affected, and the entry here is the audit trail for why.
structure A field added or removed, a rule created. Everyone — this is the full round, and the only class that should cost one.
record Something written down that was already true, or noted as conditional. Nobody yet — it exists so the next decision does not start from zero.

This page is assembled from the provenance lists in rules/*.js — it has no content of its own and cannot disagree with them. Git answers what changed in the files; this answers what changed in the decisions.
